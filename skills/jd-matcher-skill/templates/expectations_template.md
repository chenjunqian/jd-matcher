# Job Expectations & Constraints

The AI Agent strictly applies these constraints and preferences during JD filtering and evaluation:

---

## 1. Hard Constraints (Strict Veto)
- **Work Model**: Must support 100% Remote work.
- **Geographic & Timezone Limitations**:
  - Worldwide / Anywhere in the World, or APAC / EMEA friendly timezones.
  - **Do NOT accept**: Jobs strictly requiring "US Only", "Must be US Citizen", or "Must reside within North America".
- **Target Role Titles**:
  - Full Stack Engineer / Senior Full Stack Developer
  - Backend Engineer / Systems Engineer
  - Frontend Engineer / Web Developer
  - Software Engineer / Application Developer
- **Minimum Compensation Floor (when disclosed)**:
  - Not lower than $60,000 USD / year (undisclosed salary is acceptable and will not trigger rejection).

---

## 2. Strong Preferences (Positive Modifiers)
- **Tech Stack**: TypeScript, React, Next.js, Node.js, Go, PostgreSQL, Cloudflare / Serverless architectures.
- **Team Culture**: Async-first communication, emphasis on software craftsmanship and automated testing.
- **Domains**: Developer Tools (DevTools), AI-powered applications, B2B SaaS platforms.
